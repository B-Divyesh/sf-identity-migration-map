Privacy, kept local.

Identity migrations reveal sensitive paths and records. This product is designed so that work stays on your device.

CLI and browser demo

The CLI reads only the local paths you declare and writes only to the output directory you choose. It has no telemetry or network code. Text pasted into the browser demo is processed in memory and is not uploaded, logged, or saved.

License data

If you buy or restore the optional Field Kit, the license token and its last verification result are stored in your browser’s local storage. A verification request sends that token to Sociobot no more than once per day. You can remove it by clearing site storage.

Payments

Sociobot’s hosted billing service and Dodo, the merchant of record, process checkout information under their own policies. This site does not receive or store payment card details.

Hosting and requests

Normal hosting infrastructure may process short-lived request metadata such as IP address, requested path, and user agent for security and reliability. There are no analytics cookies, advertising trackers, or third-party fonts.

Contact

For privacy requests, email privacy@sociobot.in.
