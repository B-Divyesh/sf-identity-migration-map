How it works

Create an owner-ready migration map

  1. 01

    List identifiers and sources

    Name each old and new identifier, local path, owner, and rollback step.

  2. 02

    Run the read-only scan

    The CLI records literal matches with file, line, column, source type, and redacted context.

  3. 03

    Review with every owner

    Resolve unowned hits and confirm external records before changing any identity.

Limits and privacy

Know what the map does not do

A string match is evidence for a person to review. It never grants permission.

  • No account changesThe CLI does not rename, provision, or authenticate users.
  • No database writesIt scans files and read-only exports you declare.
  • No automatic approvalExternal records always require confirmation from their owners.
